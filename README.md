# 紙くらべ

A判・B判・はがき・F号の紙サイズを、実寸比で視覚的に比較できるシンプルなサイトです。

## ローカルで実行

```sh
npm ci
npm run dev
```

## GitHub Pages への公開

`main` ブランチへ push すると、GitHub Actions がビルドして GitHub Pages にデプロイします。Actions タブから実行状況を確認できます。

初回のみ、GitHub リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選んでください。

公開先: <https://tamura-kami.github.io/kami-kurabe/>
