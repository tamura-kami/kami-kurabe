# サイト要件

## 目的

紙サイズを視覚的に比較できるサイト

## ページ構成

1 ページのみ。

### ヘッダー

- サイト名
- GitHub へのリンク

### Features

- docs/paper_size.txt にある紙のサイズを視覚的に比較できるようにする。
- チェックボックスを用意し、選択した紙同士を比較できる。このとき選択されていない他の紙は薄く表示して目立たないようにする。
- docs/sample1.webp, docs/sample2.webp のような比較ができるのが理想だが、他に良い案あればこれにこだわらない。
- シンプルな UI
- 高速
- オープンソース

### Footer

- Copyright

## デザイン

- シンプル
- 白を基調
- アクセントカラーは青
- PC / スマートフォン対応

## 技術

- React
- TypeScript
- Vite
- CSS
- 外部 UI ライブラリは使用しない

## その他

- SPA
- バックエンドなし
- API 通信なし
- アニメーションは最低限
